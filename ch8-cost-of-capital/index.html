Cost of Long-Term Debt

ต้นทุนก่อนภาษีและหลังภาษี

kd

kd ≈ [INT + (M − Nd) ÷ n] ÷ [(M + Nd) ÷ 2]

Dune: หุ้นกู้พาร์ 1,000 คูปอง 9% อายุ 20 ปี ขายได้ 980 ค่าใช้จ่ายในการออก 2% ของพาร์

คำนวณหา kd ก่อนภาษี

INT = Nd = 980 − 20 =

kd ≈ [90 + (1,000−960)/20] ÷ [(1,000+960)/2] = %

ki เมื่อภาษี 40% = kd × 0.60 = %

Gordon Model และ CAPM

Gordon

ks = D₁ ÷ P₀ + g

คำนวณสองกรณี

ABC: P₀ = 50, D₁ = 6, g = 10% → ks = %

CAPM

ks = kRF + β(kM − kRF)

คำนวณDune: β = 1.5, kRF = 7%, kM = 11%

ks = 7% + 1.5 × (11% − 7%) = %

kr and ks*

กำไรสะสม kr = ks · หุ้นใหม่ ks* = D₁ ÷ [P₀(1−F)] + g

คำนวณABC: D₁ = 3, P₀ = 50, F = 10%, g = 5%

ks (กำไรสะสม) = 3 ÷ 50 + 5% = %

ks* = 3 ÷ (50 × 0.90) + 5% = % ต้นทุนเพิ่มจากค่าใช้จ่ายออก = จุด %

  • ki = kd(1 − T) · kp = Dp ÷ Np (ไม่ปรับภาษี)
  • ks = D₁/P₀ + g หรือ kRF + β(kM − kRF)

  • WACC = Σ น้ำหนัก × ต้นทุนหลังภาษี น้ำหนักรวม 1.0
